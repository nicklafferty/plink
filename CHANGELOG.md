# Changelog

## v1.0.3 - 2026-07-02

- Added drag-over activation for the menu bar droplet: dragging supported HEIC/HEIF files over the icon opens the popover in drop-ready mode.
- Added direct drop-to-menu-bar conversion for HEIC/HEIF files.
- Removed the first-launch auto-popover so Plink opens only on click, supported file drag-over, file-open handoff, or explicit reopen.
- Made app icon generation non-blocking during local builds so packaging warnings do not block development builds.

## v1.0.2 - 2026-06-23

- Added custom destination folder support.
- Fixed invisible header buttons.

## v1.0.1 - 2026-06-23

- Surfaced the popover on app launch/reopen.
- Added the droplet mark to the in-app header.

## v1.0.0 - 2026-06-23

- Added Developer ID signing and notarization support.
- Added the initial native macOS HEIC/HEIF to JPG menu bar app.
